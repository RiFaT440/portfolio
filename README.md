# Rifat | Portfolio

Personal portfolio of **A S M Tanvir Hossain (Rifat)**, a web developer who bridges software engineering and scientific simulation.

**Live site:** [https://RiFaT440.github.io/](https://rifat440.github.io/portfolio/)

## Features

- Clean, minimal one-page design with a dark and light theme (icon toggle in the header)
- Fully responsive: phone, tablet, laptop and large screens
- Sections: intro, current focus, tech stack, office and design skills, contact
- Single file. No framework, no build step, no dependencies
- Profile photo is embedded in the file, so nothing else needs to be uploaded

## Tech

HTML5 and CSS3, with a few lines of JavaScript for the theme switch.

## Run locally

Open `index.html` in any browser. No setup needed.

## Host on GitHub Pages

1. Create a new repository on GitHub. Naming it `RiFaT440.github.io` puts the site at the root of your GitHub address.
2. Upload `index.html` and `README.md`, then commit.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. Wait 1 to 2 minutes. The site will be live at `https://RiFaT440.github.io/`.

If the page looks unchanged after an update, hard refresh with `Ctrl + Shift + R` (`Cmd + Shift + R` on Mac).

## Customize

All content lives in `index.html`:

- **Text and links:** edit the HTML in each `<section>`
- **Skill bars:** change the `width` value in each `<b style="width:80%">`
- **Colors:** edit the variables at the top of the `<style>` block (`--bg`, `--ink`, `--accent`)

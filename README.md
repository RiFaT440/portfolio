# Rifat · Portfolio

Personal portfolio of A S M Tanvir Hossain. Plain HTML and CSS, no build step.

## Host on GitHub Pages
1. Create a new repository on GitHub (for a main site, name it `RiFaT440.github.io`).
2. Upload everything in this folder: `index.html`, `assets/`, `.nojekyll` and this README.
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. Wait a minute. Your site will be live at `https://RiFaT440.github.io/` (or `https://RiFaT440.github.io/<repo-name>/`).
